# K-Math Diagnostic

수학 진단 앱 K-Math Diagnostic의 UI 목업 프로젝트입니다.

## 화면 구성

| 화면 | 설명 |
|------|------|
| 대시보드 | 현재 수학 위치, AI 구멍 분석, 스킬트리 |
| 진단 테스트 | 10분·20문제 진단 |
| 수학 구멍 | 단원별 개념·계산·실수 분석 |
| 학습 로드맵 | 스킬트리 기반 학습 경로 |
| 학습지 출력 | PDF 생성·QR 채점·부모 리포트 |

## 브랜드

- **앱명**: K-Math Diagnostic
- **스튜디오**: MathTree Studio
- **컬러**: Primary Green `#244A36` / Accent Green `#7FB685`
